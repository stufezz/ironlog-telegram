# TrainApp — дневник тренировок в Telegram

TrainApp помогает планировать тренировки, записывать результаты каждого подхода и следить за прогрессом прямо в Telegram.

## Возможности

- создание собственных тренировочных программ;
- расписание программ по дням недели;
- планирование тренировки на любую дату в календаре;
- учёт веса, повторений и RIR для каждого подхода;
- добавление и удаление упражнений во время тренировки;
- заметки к тренировкам и отдельным упражнениям;
- подсказки с результатами двух последних тренировок;
- таймер отдыха на 90 секунд;
- сохранение активной тренировки и таймера после перезапуска;
- история завершённых тренировок;
- общий тренировочный тоннаж;
- графики прогресса по программам и упражнениям;
- светлая, тёмная и системная темы;
- резервная копия данных в JSON;
- выгрузка истории в CSV;
- восстановление данных из файла;
- локальное хранение без Google Sheets и регистрации.

Оригинальный IronLog для iPhone остаётся отдельным приложением и не изменяется.
